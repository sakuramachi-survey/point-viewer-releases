# 桜町測量ポイントビューア Portable

桜町測量が開発する、土地家屋調査や測量の実務向けのWindowsアプリです。点群や3D Gaussian Splatting（3DGS）データを表示し、距離・高低差・面積の計測に使えます。断面図・等高線・建物平面図の作成や土量計算、成果に応じたPDF・DXF出力にも対応します。

## ダウンロード

初回の試用版を準備中です。公開後は配布ZIP、動作確認済みの環境、利用できる機能を、リリースごとに案内します。

[Releases（配布ページ）](https://github.com/sakuramachi-survey/point-viewer-releases/releases)

## Windowsでの起動

1. 配布ページからWindows向けのPortable ZIPをダウンロードします。
2. ZIPの中身をすべて展開します。
3. 展開先の `SakuramachiPointViewer.exe` を起動します。`app` フォルダと付属ファイルは、ZIPを展開したときの配置で使います。

起動時にWebView2 Runtimeの導入を案内された場合は、Microsoftの配布ページからEvergreen Runtimeを入手してください。 [Microsoft Edge WebView2](https://developer.microsoft.com/microsoft-edge/webview2/)
